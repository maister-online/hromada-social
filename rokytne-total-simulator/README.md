# Рокитне: Життя громади — Total Simulator

Початковий браузерний прототип для подальшої розробки.

## Запуск
Потрібен Node.js 20+.
```bash
cd rokytne-total-simulator
npm install
npm run dev
```
Для окремого тесту чату в іншому терміналі:
```bash
npm run server
```
У вкладці «Система» підключись до `http://localhost:3001`.

## Наразі реалізовано
- карта OpenStreetMap через Leaflet;
- маркер персонажа і пересування WASD/стрілками;
- локальне збереження стану;
- ролі, гроші, енергія, довіра, репутація;
- базові ігрові події та локальна стрічка дописів;
- базовий Socket.IO чат-сервер.

## Що ще не реалізовано
Це не завершена GTA/Sims-гра. Немає повної геометрії всіх 25 населених пунктів, реальної навігації по дорогах, колізій, анімацій, транспорту, повноцінного NPC AI, реєстрації користувачів, серверної БД, приватних повідомлень, модерації, реальних інтеграцій соціальних мереж і новин.

Координати та POI — орієнтовні демонстраційні точки, не перевірені адреси. Карта зараз OpenStreetMap, а не Google Maps. Для переходу на Google Maps потрібні Maps JavaScript API key, білінг та адаптер карт.

Реальні новини/судові матеріали мають надходити тільки з дозволених публічних джерел, з URL, датою та позначкою перевірки. Приватні профілі, закриті групи та особисті повідомлення не збираються. Вигадані ігрові сюжети завжди маркуються окремо від реальних фактів.
